Kalkulator Medan Magnet Berbasis Java

Java • NetBeans IDE • Analisis Elektromagnetika
Problem

Perhitungan manual nilai kuat medan magnet sering kali memakan waktu dan rentan terhadap kekeliruan perhitungan matematis ketika menganalisis karakteristik kawat penghantar.

Solution

Membangun aplikasi desktop dengan antarmuka grafis di NetBeans untuk memproses rumus medan magnet secara otomatis berdasarkan variabel masukan.

Fitur & Parameter

Pilihan konduktor (Kawat Lurus, Solenoida) dengan parameter input: Arus listrik (I), Jarak titik (r), dan Jumlah lilitan (N).

Development Process
  1. Merumuskan persamaan fisika medan magnet kawat lurus dan solenoida.
  2. Merancang form input dan validasi tipe data di NetBeans.
  3. Mengimplementasikan logika algoritma perhitungan dalam Java.
  4. Menguji validitas hasil perhitungan program dengan metode perhitungan manual.

Perancangan Rangkaian Decoder 3x5 Berbasis Gerbang NOR

Gerbang NOR • 7-Segment Display • Indikator LED • Breadboard
Problem

Kebutuhan untuk membuktikan prinsip kerja decoding sinyal biner dari perumusan tabel kebenaran teoritis ke dalam wujud fisik rangkaian sirkuit digital.

Solution

Merancang kombinasi gerbang logika NOR pada breadboard yang memetakan 3 jalur input ke 5 jalur output dengan verifikasi visual 7-segment dan LED.

Development Process
  1. Menyusun tabel kebenaran relasi logika 3-input menjadi 5-output diskrit.
  2. Menyederhanakan fungsi logika agar dapat diimplementasikan seluruhnya menggunakan gerbang NOR.
  3. Merakit pengkabelan sirkuit pada breadboard beserta resistor pembatas arus.
  4. Melakukan validasi kondisi aktif setiap output LED sesuai kombinasi input 7-segment.

Lampu Otomatis Sensor Gerak Berbasis Mikrokontroler

Arduino Uno • Arduino IDE • C/C++ • Sensor Gerak • Transistor
Problem

Pemborosan energi listrik akibat penerangan ruangan yang terus menyala ketika tidak ada aktivitas pengguna.

Solution

Memanfaatkan mikrokontroler Arduino Uno untuk membaca sinyal perubahan dari sensor gerak dan mengendalikan pensaklaran transistor sebagai sakelar elektronik beban lampu.

Development Process
  1. Menghubungkan sensor gerak ke pin input digital mikroprosesor Arduino.
  2. Merangkai transistor bipolar sebagai driver sakelar untuk mengalirkan arus ke lampu.
  3. Menulis dan mengunggah kode firmware menggunakan Arduino IDE (bahasa C/C++).
  4. Menguji keandalan deteksi sensor gerak dan waktu tunda pemutusan sakelar.
